# MintMe Token Deployer

Deploy tokens on MintMe blockchain without sharing private keys.

## Features
- 🔒 Secure - Private key stays on server
- 💰 Fixed cost: 4,000 MINTME
- 🦊 MetaMask integration
- 📱 Mobile responsive
- ⚡ Fast deployment

## Setup

1. Clone repository
2. Install dependencies: `pip install -r requirements.txt`
3. Set environment variable: `MASTER_PRIVATE_KEY`
4. Deploy to Vercel

## Environment Variables

- `MASTER_PRIVATE_KEY`: Your wallet private key (without 0x)
